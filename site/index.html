Setting up, once

    

      
        

          Linux or macOS
          Install Python, MySQL and the rest, then tools/devdb.sh up starts private copies of all four databases. No passwords, nothing touches a server you already run.
          Setting up
        

        

          Windows
          Through WSL, Ubuntu inside Windows, about twenty minutes once. PowerShell can't feed a file to a database with <, so every README command would fail there.
          The Windows guide
        

        

          Docker
          docker compose up -d runs the same versions CI uses, on the same ports. You still install the client programs the tests call.
          Details
        

        

          Did ALX's MongoDB?
          That was an older MongoDB. mongo is now mongosh, insert() is insertOne(), and PyMongo 4 removed the old methods.
